# 音乐搜索下载工具

基于 `flac.music.hi.cn` 网站接口的 Python 桌面程序。

## 运行

```
python music_downloader.py
```

**依赖**：`pip install pygame numpy pyaudio`（三个包，约 50MB）
- pygame：解码音频为 PCM 数据
- numpy：音频数据处理
- pyaudio：低延迟音频输出（支持精确 seek）

三者缺一时自动回退到系统播放器模式（功能降级，无暂停/跳转）。

## 功能

| 功能 | 说明 |
|------|------|
| 搜索 | 输入歌手名/歌曲名，支持酷我(K)和网易云(W)双平台 |
| 加载全部 | 自动翻页加载所有搜索结果（无需手动滚动） |
| 播放 | 选中歌曲双击或点"播放选中"；内嵌播放（pyaudio+numpy），支持暂停/继续 |
| 进度条 | 实时显示播放进度，可点击/拖动跳转，暂停时也可跳转 |
| 下载 | 选中一首或多首（Ctrl/Shift 多选）后点"下载选中"，串行下载 |
| 音质策略 | 优先 MP3 极高 320K；无 320K 时用普通 128K（FLAC 不参与） |
| 歌词 | "下载歌词"默认勾选，随每首歌下载同名 .lrc 文件 |
| 保存目录 | 下拉框可选择历史路径，也可"浏览"弹窗选择，自动持久化 |

## 使用流程

1. 输入关键词（如"周杰伦"），点击"搜索"
2. 首页显示 20 条，点"加载全部"获取全部结果
3. 单击选中歌曲，Ctrl+单击/Shift+单击 多选
4. 双击或点"▶ 播放选中"试听
5. 点"⬇ 下载选中"批量下载到保存目录

## 限流说明

网站对频繁请求有临时限流（表现为搜索返回总数但列表为空，或 getUrl 报错）。
程序已内置防护：

- 每次 API 请求间隔 ≥0.8 秒
- 翻页间隔 1.5 秒
- 失败自动重试（指数退避）
- 搜索空结果自动等待重试

若仍遇限流，等待 1-2 分钟即可恢复。

## 可选增强

```
pip install pygame
```

安装后播放使用内嵌 pygame 混音器（界面内播放/停止可控）；
不安装则自动回退到系统默认播放器打开在线音频链接。

## 文件结构

```
music_downloader.py   # 主程序（单文件）
启动音乐下载.vbs      # VBS 启动器（双击无控制台窗口运行）
config.json           # 配置文件（保存目录历史，自动生成）
临时/                 # 播放临时文件夹（自动清理）
_analysis/            # 网站逆向分析材料（JS源码、API测试结果）
```
